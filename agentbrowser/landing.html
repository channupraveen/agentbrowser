agentbrowser: a fast browser for AI agents

AI agents usually browse with screenshots, which is slow and expensive. agentbrowser gives them the page as compact text, lets them act by exact element reference, and replays tasks they've done before with no AI at all.

What makes it different

Text, not screenshots

Each page comes back as a short list of elements with refs (e11 link …) plus readable text, and follow-up steps only send what changed.

Record once, replay instantly

Finished tasks are saved as skills with parameters. Replays run with no AI; if the site changed, the agent takes over at the exact step that broke.

API discovery

JSON calls a site makes while you browse are catalogued, so the agent can fetch the data directly instead of clicking through the UI.

Works with Claude (MCP)

Add it as a connector and Claude drives it. No separate AI account or API key. Runs locally, through a tunnel, or deployed like this one.
